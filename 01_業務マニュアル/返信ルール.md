# 返信ルール（賃貸経営メール業務）

このファイルは、坂本の代わりにメール返信を行う人（自動ツール・AI社員を含む）のための業務マニュアルです。
**迷ったときは返信せず、坂本に確認する**ことを最優先とします。

最終更新：2026-11-21

---

## 0. 基本方針

| 項目 | 内容 |
|---|---|
| 対象 | 管理会社から届く、所有する賃貸物件に関するメール（相手先は「管理会社一覧.md」に載っている会社だけ） |
| 対象外 | **司法書士業務のメールは一切扱わない**（守秘義務のため。読まない・返信しない・転送しない） |
| 差出人名 | 坂本 |
| 文体 | 丁寧だが簡潔。「いつもお世話になります。坂本です。」で始め、感謝の一言で締める |
| 返信の目安 | 受信から1営業日以内 |

## 1. 現在の段階

- [x] **第1段階**：自動ツールが定型文の下書きを作り、坂本が確認して送信する
- [ ] **第2段階**：AI社員が定型外のメールも下書きし、坂本が確認して送信する
- [ ] **第3段階**：下の「自動送信してよい」条件のものだけ、AI社員が送信まで行う

※ 段階を進めるときは、坂本がこの欄のチェックを更新する。チェックがない段階の作業は行わない。

---

## 2. メールの種類ごとの対応

### A. 修繕工事などの見積の連絡

| 条件 | 対応 |
|---|---|
| 見積金額（税込）が **5万円以下** | 承知の返信をする（テンプレート：`02_返信テンプレート/見積承知.txt`） |
| 見積金額が **5万円を超える** | **返信しない。坂本に確認を依頼する** |
| 金額が書かれていない・読み取れない | **返信しない。坂本に確認を依頼する** |
| 複数の見積（相見積）から選ぶ必要がある | **返信しない。坂本に確認を依頼する** |
| 緊急対応（漏水・設備故障で入居者が困っている等） | 坂本にすぐ知らせる |

- 金額は、メール本文と添付の見積書（PDF等）の両方を確認する。合計額（税込）で判断する。
- 同じ工事で追加見積が来た場合は、**前回分との合計**で判断する。

### B. 入居・退去の報告

| 条件 | 対応 |
|---|---|
| 入居・退去・解約・契約の**報告のみ** | 承知の返信をする（テンプレート：`02_返信テンプレート/入退去承知.txt`） |
| 原状回復工事・費用の見積が含まれる | 「A. 見積」のルールで判断する |
| 何かの判断・回答を求められている（家賃の設定、募集条件、敷金精算など） | **返信しない。坂本に確認を依頼する** |

### C. 上記以外のメール

- 定型文では返信しない。内容を要約して坂本に確認を依頼する。
- 返信が必要なときは、`03_返信事例` の近い事例を参考に下書きを作る（第2段階以降）。

---

## 3. 自動送信してよい条件（第3段階で使用）

次の**すべて**を満たすときだけ、確認なしで送信してよい。

1. 送信者が「管理会社一覧.md」に載っている
2. 上の表で「承知の返信をする」に当たる
3. テンプレートの文面をそのまま使う（独自の文章を加えない）
4. 見積の場合は、金額が5万円以下だとはっきり読み取れる

一つでも当てはまらない、または迷う場合は送信せず、下書きにとどめる。

---

## 4. 坂本への確認依頼の書き方

```
【要確認】(管理会社名) (件名)
・物件／部屋：
・内容の要約：
・金額：
・確認したいこと：
・期限（あれば）：
```

## 5. やってはいけないこと

- 司法書士業務のメールを読む・扱う
- 5万円を超える見積、または金額不明の見積に承知の返信をする
- 金額・日程・契約条件について、坂本の確認なしに約束をする
- 管理会社一覧に載っていない相手に返信する
- パスワードなどの認証情報をメールやファイルに書く
