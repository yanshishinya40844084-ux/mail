# 返信事例の残し方

定型文では済まなかったメールに返信したら、1件ごとにファイルを作って残してください。
AI社員が「坂本さんならどう返すか」を学ぶための、いちばん大事な教材になります。

- ファイル名：`2026-11-21_〇〇管理_見積(10万円).md` のように、日付・相手・内容が分かる名前にする
- 個人情報（入居者の氏名・電話番号など）は「〇〇様」のように伏せて構いません

---

（以下をコピーして使ってください）

```
# 件名：

## 届いたメール（要点だけでも可）


## 送った返信


## 判断のポイント（なぜそう返したか）
例：金額が5万円を超えていたが、前回も同じ業者で問題なかったので承知した
```
