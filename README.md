# 賃貸経営_メール業務

所有する賃貸物件について、管理会社とのメールのやりとりをまとめた業務フォルダです。
坂本本人、自動ツール、将来のAI社員が、同じ資料を見て仕事をします。

| フォルダ | 中身 | 主に使う人 |
|---|---|---|
| `01_業務マニュアル/` | 返信ルール（判断基準）・管理会社一覧・物件一覧 | 全員（AI社員は最初に読む） |
| `02_返信テンプレート/` | 定型の返信文 | 全員（自動ツールもここから読む） |
| `03_返信事例/` | 定型外のメールと実際に送った返信 | AI社員の教材 |
| `04_プログラム/` | 返信の下書きを自動作成するツール | PC で自動実行 |
| `05_記録/` | 処理済みの記録・ログ（自動で作られる） | 自動ツール |

## 大事な決まり

- **パスワードはこのフォルダに置かない。** PC のユーザーフォルダにある `auto_draft_secrets.toml` に置く（`04_プログラム/README.md` 参照）。
- **司法書士業務のメールは扱わない。**
- 返信の判断基準は `01_業務マニュアル/返信ルール.md` にまとめる。ルールを変えたら、まずこのファイルを直す。
- 定型文を変えたいときは `02_返信テンプレート/` のファイルを直すだけでよい（自動ツールにもそのまま反映される）。

## 進め方

1. **第1段階（今）**：自動ツールが定型の下書きを作り、坂本が確認して送信。定型外の返信は `03_返信事例` に貯める。
2. **第2段階**：AI社員がマニュアルと事例をもとに、定型外の下書きも作る。送信は坂本。
3. **第3段階**：返信ルールの「自動送信してよい条件」を満たすものだけ、AI社員が送信。

管理会社とのやりとりは、段階的に賃貸経営用の Gmail アドレスへ移していく予定（AI社員が扱いやすいため）。
