# 返信下書き 自動作成ツール

管理会社から届く「見積のご連絡」「入退去のご報告」などのメールに対して、
**定型文の返信を自動で「下書き」フォルダに作る**ツールです。

- メールを**送信することはありません**。下書きを開き、確認してから送信ボタンを押すだけです。
- 受信メールは**読み取り専用**で開くため、既読・未読の状態も変わりません。
- Yahoo!メールとGmailの両方に対応しています（IMAPという仕組みで接続します）。
- 一度下書きを作ったメールには、二度と作りません。

```
管理会社からメール ──▶ このツール（15分ごとに自動実行）──▶ 下書きフォルダに返信文
                                                             │
                                          あなたが内容を確認して「送信」
```

具体的な内容を書く必要があるメール（ルールに一致しないメール）は、そのまま残ります。

---

## 1. 準備（最初の1回だけ）

### 1-1. Python を入れる
- **Windows**：https://www.python.org/downloads/ から 3.11 以上をインストールします。
  インストール画面で **「Add python.exe to PATH」にチェック**を入れてください。
- **Mac**：ターミナルで `python3 --version` を実行し、3.11 以上でなければ上のサイトから入れます。

### 1-2. このフォルダを PC に置く
GitHub の「Code」→「Download ZIP」でダウンロードし、
分かりやすい場所（例：`ドキュメント\mail`）に展開します。

### 1-3. Yahoo!メールで IMAP を有効にする
1. PC のブラウザで Yahoo!メールを開き、右上の「設定・利用規約」→「メールの設定」
2. 「IMAP/POP/SMTPアクセスとメール転送」を開く
3. 「Yahoo! JAPAN公式サービス以外からのアクセスも有効にする」を選び、IMAP を有効にして保存

※ Yahoo! JAPAN ID にパスワードを設定していない（SMS認証だけでログインしている）場合は、
先にパスワードを設定してください。画面の表記は変わることがあります。

### 1-4. （Gmailも使う場合）アプリ パスワードを作る
1. Google アカウントで **2段階認証** を有効にする
2. https://myaccount.google.com/apppasswords で「アプリ パスワード」を作成（16桁）
3. その16桁を設定ファイルの `password` に書きます（普段のパスワードではありません）

## 2. 設定ファイルを作る

1. `config.example.toml` をコピーして、名前を **`config.toml`** に変えます。
2. メモ帳などで開き、次の項目を書き換えます。

| 項目 | 書くこと |
|---|---|
| `user` | ご自身のメールアドレス |
| `password` | パスワード（Gmail はアプリ パスワード） |
| `from_contains` | **管理会社のメールアドレス**（例：`"@abc-kanri.co.jp"`）。複数社なら `["@a社.jp", "@b社.jp"]` |
| `subject_contains` | 件名に含まれる言葉（見積なら `"見積"` など） |
| `template` | 返信文（頂いた例文が入っています） |

Gmail も使う場合は、Gmail の `enabled = false` を `true` に変えます。

> ⚠ `config.toml` にはパスワードが入ります。人に渡したり、GitHubに上げたりしないでください
> （このリポジトリでは自動的に除外されます）。

### ルールの例：管理会社ごとに文面を変える
上から順に判定され、最初に一致したルールが使われます。

```toml
[[rules]]
name = "A社 見積"
from_contains = ["@a-kanri.co.jp"]
subject_contains = ["見積"]
template = """
A社 田中様

いつもお世話になります。坂本です。
見積書を確認し、承知しました。
...
"""
```

`subject_excludes = ["再見積", "至急"]` のように書くと、その言葉が件名にあるメールは対象外になり、
ご自身で返信する分として残ります。

## 3. 動かしてみる

フォルダを開いた状態でコマンド（Windows は「ターミナル」または「コマンドプロンプト」、
Mac は「ターミナル」）を開き、`cd` でこのフォルダに移動してから実行します。
（Mac では `python` を `python3` に読み替えてください。）

```bash
# ① 接続確認：フォルダ一覧が出れば OK
python auto_draft.py --list-folders

# ② 試しに実行：どのメールに下書きを作るか「表示だけ」します（何も保存しません）
python auto_draft.py --dry-run

# ③ 初回だけ：すでに返信済みのメールに下書きを作らないよう、今あるメールを「処理済み」にします
python auto_draft.py --init

# ④ 本番：新しく届いたメールに下書きを作ります
python auto_draft.py
```

②の表示を見て、対象のメールが正しく選ばれているか確認してください。
意図しないメールが出てきたら `from_contains` や `subject_contains` を調整します。

## 4. 自動で定期実行する

### Windows（タスク スケジューラ）
1. `run_auto_draft.bat` をダブルクリックして、正常に動くことを確認
2. スタートメニューで「タスク スケジューラ」を開き、「基本タスクの作成」
3. 名前：`返信下書き` / トリガー：「毎日」 / 操作：「プログラムの開始」で `run_auto_draft.bat` を選択
4. 作成後、タスクのプロパティ →「トリガー」→「編集」で
   **「繰り返し間隔：15分」「継続時間：無期限」** にチェック

### Mac（cron）
ターミナルで `crontab -e` を実行し、次の1行を追加します（パスはご自身の環境に合わせて変更）。

```
*/15 * * * * cd ~/Documents/mail && /usr/bin/python3 auto_draft.py >> auto_draft.log 2>&1
```

PC の電源が入っている間だけ動きます。電源を切っている間に届いたメールも、
次に起動したときに（`lookback_days` 日以内のものは）下書きが作られます。

## 5. よくある質問

**Q. 下書きはどこにできますか？**
Yahoo!メールは「下書き」フォルダ、Gmail は「下書き」ラベルです。
スマホのアプリにも同期されるので、外出先で確認して送信できます。

**Q. ログインできないと表示されます。**
Yahoo!は 1-3 の IMAP 設定、Gmail は 1-4 のアプリ パスワードを確認してください。

**Q. 同じメールに下書きが二重にできませんか？**
作成済みのメールは `processed.json` に記録され、二度と作りません。
すでに返信済み（返信マークが付いた）メールも対象外です。

**Q. 具体的な内容が必要なメールは？**
ルールに一致しないので、下書きは作られません。ご自身で書くか、Claude に
「このメールに『〇〇』と伝える返信を書いて」と頼んでください。
